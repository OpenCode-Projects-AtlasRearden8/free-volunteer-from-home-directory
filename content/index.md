# Kitchen-Table Volunteering

Real volunteering you can do from a kitchen table, in slippers, with nothing
more than a laptop, some yarn, or a phone. No commute, no uniform, no
accounts to manage beyond a simple signup.

This directory covers six kinds of remote-first volunteering:

- **[Archive transcription](archive-transcription.html)** — turn historical documents into searchable text
- **[Citizen science](citizen-science.html)** — help researchers classify galaxies, penguins, and cancer cells
- **[Remote crisis-line volunteering](remote-crisis-line.html)** — listen to people in hard moments, via text
- **[Online tutoring](online-tutoring.html)** — help a student get unstuck in algebra
- **[Accessibility testing](accessibility-testing.html)** — make websites and apps work for everyone
- **[Craft drives](craft-drives.html)** — knit, crochet, and sew for people and animals in need

Every entry lists:

- a realistic **time commitment**
- **age notes** (some programs need adults, some welcome teens)
- plain-English **signing-up steps**

Not sure where to start? Jump straight to the
**[pick-your-first-project worksheet](worksheet.html)** — answer a few
questions and get a suggested match and a first-week plan.

## How this site works

- The source is plain **Markdown** in the `content/` folder; the HTML is
  generated by a tiny build script (`build.py`) you can run locally.
- No accounts, no cookies, no analytics, no tracking of any kind.
- Everything runs from your own machine: build it and open the files in a
  browser, or serve the `site/` folder any way you like.

## A friendly word before you begin

Volunteering from home has one thing in common with all volunteering: the
moment that matters is the moment you show up the first time. Start with one
project. Do it once. See how it feels. You can always add more — and it is
completely fine to decide a project is not for you and try another.
